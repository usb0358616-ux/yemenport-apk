# نظام المنافذ والجوازات (Smart Border Ports & Passports System)

تطبيق أندرويد أصلي (Native Android) مبني بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** مع دعم كامل للغة العربية واتجاه **RTL** للعمل الميداني في المنافذ الحدودية (المطارات، الموانئ، والنقاط البرية).

## أبرز القدرات والمكونات
- **العمل بدون إنترنت أولاً (Offline-First)**: قاعدة بيانات **Room (SQLite)** عالية السعة مع تشفير الحقول الحساسة عبر **Android Keystore (AES-256-GCM)** ومزامنة سحابية آمنة مع **Firebase Firestore** بعد تسجيل الدخول بحساب Google (`CredentialManager`).
- **فحص الجوازات والوثائق (CameraX + ML Kit + MRZ)**:
  - قراءة سطور الآلة (MRZ TD3 / TD1) مع التحقق من أرقام الفحص (Check Digits)، وحساب العمر وحالة الصلاحية تلقائياً، وتطبيع الأرقام الهندية (`٠-٩`).
- **محرك الحراسة الأمنية الفورية (Watchlist Guard)**:
  - مطابقة لحظية للمسافرين والوثائق المستوردة مع قوائم الممنوعين من السفر، البلاغات الأمنية النشطة، والجوازات المضبوطة مع تنبيه صوتي واهتزازي فوري.
- **مركز الاستيراد الموحد (Excel / CSV / PDF / الصور)**:
  - معالجة ملفات `.xlsx` و `.csv` و `.pdf` (مع استخلاص النصوص أو تحويل الصفحات الممسوحة إلى صور عبر `PdfRenderer` + `ML Kit OCR`) وتنقية النصوص العربية ومراجعة الجدول قبل الحفظ.
- **الوحدات السيادية المتكاملة**:
  - إدارة المسافرين والدمج الذكي (Smart Merge) وبطاقة QR وطباعة/تصدير CSV و XLSX و PDF.
  - البلاغات الأمنية، التحركات الدورية، الجوازات المضبوطة، تأشيرات الخارجية وكشوفات الرحلات (MOFA & Manifests)، تصاريح المرور، شؤون الأجانب واللاجئين، قضايا الجنسية ومؤشرات SLA، الوكالات المراقبة، المراسلات الرسمية، المنافذ الـ 19، وصلاحيات الضباط (RBAC) مع البصمة وسجل التدقيق غير القابل للتعديل.
- **الذكاء التحليلي (Firebase AI Logic)**:
  - تحليل الأنماط واكتشاف التزوير المحتمل وتوليد ملخصات ميدانية ذكية عبر `Firebase.ai`.
